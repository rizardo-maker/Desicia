## Structural checks before code
- 1440×900: 1264px content width; exactly 900px chapter heights, 88px equal outer edges; nav and footer use same wrapper. Footer is inside chapter 05.
- 1024×768: 48px margins, split when space allows, natural height prevents clipped controls. Chapters need not be exact viewport heights below the desktop design target.
- 768×1024: 32px margins; stacked copy and full-width product interfaces; chapter rail suppressed when it would overlap.
- 390×844: 24px margins; short two-line headings; static lightweight scene; no desktop fixed-height trap; wrapping data controls; product graphs designed at narrow width rather than scaled screenshots.
- Scroll starts from native document position; chapter-center keyframes, no wheel interception, anchors remain real URLs. UI highlights use exact state, renderer uses damped state.
- Hero copy appears immediately; only transform/opacity enhancement ≤700ms. No loading gate.
- Trust claims remain conditional procurement topics, not certification badges.
